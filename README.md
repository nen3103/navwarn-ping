# navwarn-ping

A tiny watcher. Every 5 minutes it checks a few public navigation-warning lists
(China MSA coastal bureaus, Japan Coast Guard NAVAREA XI, NGA HYDROPAC) and, when a new
military / firing / rocket-debris item appears, starts a workflow in another repository.

No data, analysis, or contact details are kept here — only the script and the list of item IDs already seen.
